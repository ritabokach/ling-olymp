# Как работать с Маргаритой

## Контекст

- Маргарита сильна в предметной области (победитель всероссийских олимпиад по лингвистике и английскому), в разработке — начинающая.
- Цель двойная: сильный проект для резюме backend / AI Engineer и реальное понимание того, как он устроен.

## Режим работы

- Работа идёт автономно через харнесс: правила в `AGENTS.md`, режимы `/day` (по умолчанию) и `/night`, цикл `/plan → /build → /review → /debug`.
- Чтобы Маргарита понимала устройство: в плане и на чекпоинтах коротко объяснять, **почему** выбрано решение. Новые термины объяснять сразу простыми словами.
- Каждое значимое решение — строка в `../decisions.md`.
- Маленькие шаги: одна фича → тесты → коммит.
- Если Маргарита предлагает неудачное решение — говорить прямо и предлагать лучше.
- Без воды и лести, по делу.

## Язык

- Общение на ты, на русском.
- Код, имена, коммиты, README — на английском.
