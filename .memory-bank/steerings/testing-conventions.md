# Правила тестирования

- Фреймворк: pytest.
- Каждый модуль `core/` покрыт тестами.
- Шаг разработки считается готовым, когда у него есть тесты. Потом коммит.
- **Обязательный тест однозначности:** для каждой сгенерированной задачи решатель подтверждает, что все совместимые с примерами гипотезы дают одинаковые ответы на вопросы. Критерий → `../tech-details/numeral-puzzle-model.md`.
- **Изоляция ядра:** `tests/core/test_core_isolation.py` разбирает код `core/` через `ast` и падает на импорте `lingpuzzle.api`, `lingpuzzle.web`, `fastapi`, `starlette`, `uvicorn` (обычный, `from`, относительный). Второй тест запускает отдельный Python и проверяет `sys.modules`. Динамические импорты (`importlib`) не покрыты, `import *` ловит ruff (F403).
- Режим pytest `--import-mode=importlib`, без `__init__.py` в `tests/`: тесты разных типов задач могут называться одинаково.
