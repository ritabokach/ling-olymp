# Правила тестирования

- Фреймворк: pytest.
- Каждый модуль `core/` покрыт тестами.
- Шаг разработки считается готовым, когда у него есть тесты. Потом коммит.
- **Обязательный тест однозначности:** для каждой сгенерированной задачи решатель подтверждает, что все совместимые с примерами гипотезы дают одинаковые ответы на вопросы. Критерий → `../tech-details/numeral-puzzle-model.md`.
