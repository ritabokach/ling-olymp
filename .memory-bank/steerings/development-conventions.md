# Правила разработки

Общие правила харнесса (коммиты, ветки, режимы, вопросы на чекпоинтах) — в `AGENTS.md`. Здесь только то, что специфично для проекта.

## Структура репозитория

```
core/          генератор и решатель, без зависимостей от веба
api/           FastAPI
web/           frontend
tests/core/    pytest для core/
tests/api/     pytest для api/
swarm-report/  планы, отчёты харнесса
```

`core/` — отдельный модуль. Его можно тестировать и использовать независимо от `api/` и `web/`.

## Коммиты

- Маленькие, одна законченная мысль на коммит.
- Conventional Commits на английском: `feat(core): ...`, `test(core): ...`, `docs: ...`, `chore: ...`.

## Документация

- `README.md` на английском, для портфолио: что это, как запустить, как устроен генератор.
- Журнал архитектурных решений — `.memory-bank/decisions.md`. Пойдёт в статью на Хабр и на собеседования.
