# План

Сроков нет: этапы идут по порядку, без дат.

| Этап | Что сделать |
|---|---|
| 1 | Ядро: модель системы счёта, генератор, решатель, проверка однозначности, тесты |
| 2 | Backend (API: выдать задачу, принять ответ, засечь время) + БД + простой frontend |
| 3 | Таблица лидеров, деплой, строки-факты о реальных языках, статья на Хабр |
| 4 | Показ в олимпиадных сообществах, первые пользователи |

## MVP

Генератор систем счёта с проверкой однозначности → страница задачи → ввод ответа → автопроверка → время → таблица лидеров.

## После MVP

- Типы задач: морфология → системы письма → термины родства.
- ИИ-слой: подсказки, разбор решения, легенды.
- Слитное написание числительных и сегментация слов.
