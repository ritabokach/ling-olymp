# Продукт

## Суть

Программа генерирует задачи по лингвистике: дан набор примеров на незнакомом (придуманном) языке, нужно восстановить правила и перевести новые выражения. Пользователь решает задачу на время и получает место в рейтинге.

Сценарий: открыл задачу → таймер → решил → время и место в рейтинге → одна строка-факт о реальном языке.

## Почему это не повтор существующего

- Архивы и каталоги задач уже есть (например, Lingdex.org).
- Онлайн-олимпиада Onling проходит раз в год.
- Задач в мире мало: каждую составляет эксперт вручную.
- Генератор даёт бесконечный поток новых задач с гарантированно единственным решением.

## Принципы дизайна

- **Не энциклопедия.** Главное — решить задачу.
- После решения — **одна строка-факт** о реальном языке с этим явлением («Двадцатками считали, например, майя»). Это награда, не лекция. Можно пропустить.
- **Никаких лингвистических терминов в интерфейсе:** «язык, где считают двадцатками», а не «вигезимальная система».
- Фокус на лингвистике, не на случайных головоломках: каждая задача построена на явлении, которое реально есть в языках мира.

## Аудитория

Школьники-олимпиадники, кружки, учителя, любители лингвистики. Ниша маленькая, и это нормально. Реалистичная цель — 100–300 активных пользователей.

## Типы задач (порядок внедрения)

1. **Системы счёта** — MVP, самые формализуемые.
2. Морфология: аффиксы множественного числа, притяжательность («мой дом / твой дом»).
3. Системы письма: транслитерация из незнакомой письменности.
4. Термины родства.

## ИИ — вторая фаза, не в MVP

Нейросеть работает **поверх** ядра через API. Правильный ответ известен из генератора, поэтому ИИ не может ошибиться в сути.

- Подсказки во время решения.
- Разбор решения понятным языком.
- Легенда к задаче («на этом языке говорят жители вымышленного архипелага…»).
